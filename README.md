# 账页 · 记账工作台

一个**完全本地离线**的个人记账网页。纯 HTML + CSS + 原生 JavaScript，零依赖、零构建，双击 `index.html` 就能用。数据只存在你本机的 `localStorage` 里，不上传任何服务器。

> 唯一会联网的地方是「AI 分析」——只在你自己点按钮时，把**聚合后的月度摘要**发给你自己填的模型接口。

---

## 视觉与交互

整个界面是**一本摊开的书**，不再是侧边栏 + 内容区的后台布局：

- **顶部便条贴**：8 个标签直接跳到对应章节，当前页是一张微微倾斜的荧光黄便条
- **中间书页**：内容在书里滚动，书眉和书脚固定，左边缘有装订线的内阴影
- **书脚左右**：各一个翻页按钮，按章节顺序翻到上一章 / 下一章（首尾循环），也能用 `←` `→` 方向键
- **底部页码**：`03 / 08 · 统计`，像书的页码

纸张是奶油色 + 点阵纹理，卡片是**黑描边 + 硬投影**的纸片感，配马卡龙色块（薄荷 / 珊瑚 / 柠檬 / 薰衣草）。左上角的标识是几何图形：薄荷圆角块里三根上升的柱子 + 一个珊瑚色圆点，不再是「账」字方块。

- 字体默认**宋体**（书籍印刷体，和「一本书」的隐喻最搭），设置里可一键切**楷体**（更手写）或**无衬线**（最清晰）
- 数字和金额用等宽数字排版，竖排账目不会跳动

- 四张 KPI 卡各有一个主题色，扫一眼就能区分结余 / 支出 / 收入 / 预算
- 分类颜色固定：餐饮橙、交通蓝、购物红、住房紫、居家青……旧数据会自动升级配色
- 按钮按下会「压下去」（位移 + 投影消失），翻页有轻微的横向淡入
- 深色模式是「夜里的纸」：深底 + 奶油色描边

## 快速开始

直接双击 `index.html`。首次打开会载入一套示例数据（两个账本、100 多笔流水、预算、周期账单、借贷），方便你先看效果；点仪表盘顶部的「清空并开始记账」就能清空成空白账本。

也可以起一个静态服务：

```powershell
python -m http.server 8080
# 或
npx serve .
```

> 注意：用 `file://` 直接打开和用 `http://localhost` 打开属于不同 origin，`localStorage` 不互通。选定一种方式后别来回切。

## 功能

**记账**
- 支出 / 收入 / 转账三类，全局 `N` 键或顶部按钮唤起记账浮层
- 金额、分类、账户、日期、备注，支持「保存并继续」连续记
- 常用备注一键填充，「上次 ¥32 · 午餐」直接套用上次的金额和备注

**账户与账本**
- 多账户：现金 / 微信 / 支付宝 / 储蓄卡 / 信用卡
- 账户余额 = 初始余额 + 流入 − 流出，随流水增删**自动重算**
- 多账本：日常、旅行等各自独立，统计互不干扰；新建账本自动带一套默认分类

**预算**
- 总预算 + 分类预算，可设「每月通用」或「仅某月」
- 进度条、剩余金额、剩余天数日均可用；超支自动标红
- 一键复制上月单独设置的预算

**周期账单**
- 房租、会员、还款等按每月 / 每周 / 每天自动生成
- 两种模式：「自动入账」直接写进明细；关闭则进「待入账」，由你确认或忽略
- 重复运行不会重复生成（生成后自动推进下次日期）

**借贷（应收应付）**
- 我借出 / 我借入，约定还期、逾期标记
- 借出与借入**不计入收支统计**，只影响账户余额，避免虚增消费
- 结清时自动补一笔资金流水，两边同时消账；可撤销结清
- 删除借贷时可选择同时删除关联流水

**统计**
- 分类排行：金额、占比、环比、同比
- 同比 / 环比对照表（支出、收入、结余）
- 日历热力图：每天花销深浅一眼看出，近 6 个月支出柱
- 本月支出、收入、结余、日均

**AI 消费分析**
- 支持任何 OpenAI 兼容接口（DeepSeek / OpenAI / Ollama…），Base URL、Key、模型名都在设置里填
- 生成月度分析报告：一句话结论、关键发现、可执行建议、下月预算建议
- 报告存本机，可回看历史、复制
- 没配 Key 或断网时，用**本地规则引擎**照样出结论
- 发送前可在页面上展开预览将要发出的 JSON

**数据**
- 导出 / 导入 JSON 备份（含账本、流水、预算、配置）
- 导出当前账本明细 CSV（带 BOM，Excel 直接打开不乱码）
- 清空全部数据 / 重新载入示例数据

## AI 接口怎么配

1. 打开「设置 → AI 接口」
2. Base URL 填到 `/v1` 这一层，例如 DeepSeek：`https://api.deepseek.com/v1`
3. 模型名：`deepseek-chat`（OpenAI 用 `gpt-4o-mini` 之类）
4. 填 API Key（`sk-…`），点「测试连接」，成功会提示并保存
5. 回「AI 分析」页点「生成 AI 分析」

- 程序会自动在 Base URL 后面拼 `/chat/completions`，填完整地址也能识别。设置页会显示「实际请求」地址，可以先核对一眼。
- Key 明文存在浏览器 `localStorage`，不做加密。自用电脑没问题，公用电脑别填。

### 接口连不上怎么办

点「测试连接」失败时会弹出一个诊断框，里面有**请求地址、模型、Key 掩码、耗时、服务器原始响应**，还有「网络自检」结果，底部可以一键复制。对照着看：

| 现象 | 大概率原因 | 怎么办 |
| --- | --- | --- |
| 返回一整页 HTML（`<!DOCTYPE html>`） | Base URL 填成了**网页控制台**，例如 `platform.deepseek.com` | 改成 `https://api.deepseek.com/v1`。程序检测到这类地址会自动纠正并提示 |
| 401 | Key 无效、过期，或粘贴时带了引号 / 空格 / 换行 | 重新完整复制 `sk-…`；本程序会自动去掉首尾引号，但中间夹字符救不了 |
| 402 | 账户余额不足 | 去平台充值 |
| 404 | Base URL 路径不对 | DeepSeek 填 `https://api.deepseek.com/v1`，不要填 `/v1/chat/completions` 之外的路径 |
| 400 | 模型名或参数不被接受 | DeepSeek 官方：`deepseek-chat`、`deepseek-reasoner`；本机网关还支持 `deepseek-flash`、`deepseek-v4-pro` |
| 429 | 限流 / 额度用尽 / 被 WAF 拦 | 等一会儿；若响应是 HTML，说明地址不是接口 |
| 没有状态码，网络自检显示"不可达" | 网络、代理、DNS 问题 | 检查代理 / 换网络 |
| 没有状态码，但网络自检显示"可达" | 这个接口不允许浏览器直连（常见于第三方中转站） | 换官方地址，或让我加一个本地代理 |
| 提示"连接成功（回复为空）" | 鉴权与路径都正常，只是模型没吐内容 | 正常可用，直接生成分析即可 |

**实测过的正确配置（DeepSeek 官方）**：

```
Base URL   https://api.deepseek.com/v1
模型       deepseek-chat        （或本机网关的 deepseek-flash / deepseek-v4-pro）
API Key    sk-…（35 位）
```

> `https://platform.deepseek.com` 是网页控制台，**不能**当接口地址；对它发 API 请求会返回 429 + 一页 HTML，浏览器里表现为 `Failed to fetch`。

网页会先把配置清洗一遍（去掉首尾引号、空白），也能识别填了完整 `/chat/completions` 地址的情况。用的是第三方中转站时，`/models` 探测失败是正常的，以 `401/200` 的实际调用结果为准。

## 文件结构

```
.
├── index.html        # 页面骨架、SVG 图标、导航
├── styles.css        # 全部样式、浅/深色主题、响应式
├── app.js            # 全部状态、渲染、交互、存储、AI 调用
├── README.md
└── _dev/
    └── smoke.mjs     # 开发自测（Node 跑一遍核心逻辑，非交付必需）
```

程序入口是 `index.html` 末尾的 `<script src="app.js" defer>`。发布时带上 `index.html`、`styles.css`、`app.js` 三个文件即可。

## 数据存放

- 存储键：`jizhang-ledger-v1`
- 方式：`window.localStorage`
- 不在项目文件夹里，源文件不含个人数据
- 换电脑 / 换浏览器：用「导出 JSON」再「导入 JSON」

建议每次大改前先导出一次备份。JSON 备份里包含 API Key，转给别人前记得删掉 `settings.ai.apiKey`。

## 开发自测

没有构建器，语法检查 + 逻辑冒烟：

```powershell
node --check app.js
node _dev/smoke.mjs
node _dev/css-check.mjs
```

`smoke.mjs` 用最小 DOM 桩在 Node 里加载真实的 `app.js`，会检查：8 个视图能否渲染、月度/分类/账户余额/预算聚合是否一致、周期账单是否重复生成、AI 摘要与本地分析是否正常、接口请求（含本地 mock 服务）、弹窗模板、借贷联动、图标引用。

`css-check.mjs` 检查「用到的 class 是否都有样式」「引用的 CSS 变量是否都声明过」，改样式之后跑一下能抓到漏掉的规则。

## 已知限制

- 金额只记人民币，不做多币种汇率
- 借贷结清默认用当天日期，不能指定入账日
- 借贷的编辑不会重算已生成的历史流水
- 没有云同步和多人协作，靠 JSON 备份迁移
- 数据量大到几万笔时，`localStorage` 和全量渲染会开始吃力
